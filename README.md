# The Sacred Resin: Boswellia Sacra & Spatial Matrix

The Sacred Resin: Boswellia Sacra & Spatial Matrix is a holographic 6D engine by Asia Khan featuring Expert, Simple, and Kids views, a 3D geo globe, seasonal slider, spectral bands, and tree cutaways[cite: 1].

## Technology Stack
* **Three.js (r128):** Powers the 3D holographic globe, procedural botanical models, custom shaders, and interactive spatial rendering[cite: 1].
* **Vanilla JavaScript (ES6+):** Manages core application logic, animation loops, raycasting, user interactions, and mini-game mechanics[cite: 1].
* **HTML5 & CSS3:** Structures the responsive layouts, UI overlays, HUD readouts, and adaptive theme styling[cite: 1].
* **Google Fonts:** Integrates typography including Cormorant Garamond, Hanken Grotesk, IBM Plex Mono, Atkinson Hyperlegible, Baloo 2, and Young Serif[cite: 1].

## Adaptive Reading Modes
* **Expert View:** Tailored for advanced scientific, geographical, and botanical analysis with precise terminology and deep data metrics[cite: 1].
* **Simple View:** Designed for streamlined comprehension, making ecological and historical concepts accessible to general audiences[cite: 1].
* **Kids View:** Optimized for young learners, incorporating engaging interactive features, simplified descriptions, and gamified mechanics[cite: 1].
